# Customer Purchase Prediction Using Machine Learning

## Overview
This project predicts customer purchase behaviour using two machine learning models: Logistic Regression and Random Forest.

## Models
- **Logistic Regression:** A baseline classification model.
- **Random Forest:** An ensemble learning model that combines multiple decision trees.

## Dataset
The dataset contains customer details such as age, gender, annual income, purchase history, product category, website activity, and other purchasing-related features.

## Methodology
Data preprocessing, feature encoding, model training, prediction, and performance evaluation were performed using Python and Scikit-learn.

## Results
Logistic Regression achieved **82.67% accuracy**. Random Forest was also implemented for comparison, with performance evaluated using classification metrics.

## Project Files
- `logistic_regression.ipynb` — Logistic Regression implementation.
- `random_forest.ipynb` — Random Forest implementation.
- `ML_Case_Study_Report.pdf` — Detailed case study report.

## Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

## Conclusion
The project compares two classification algorithms for customer purchase prediction and evaluates their performance to understand which model is more suitable for the dataset.
